## 动作要点

总时长 **800ms**。被点击的卡片是主体，整张首页不跟随上移或拉伸。

1. 卡片向屏幕中心移动，同时缓慢展开；移动前段更明显，展开随接近中心逐渐加快。卡片中心位置和容器尺寸分别控制，不能用上边缘变化冒充位移。
2. 周围内容及卡片文字、按钮同步模糊；背景图先保持清晰，并从起点持续等比例放大。
3. 周围内容完成主要模糊后，背景继续放大并逐渐模糊；**目标页面在同一时段逐渐显现、由模糊变清晰**。不能等背景模糊基本结束才切到目标页。
4. 800ms结束时目标页面完全清晰、可交互；旧页面退出。淡出只是转场的一部分，不能替代目标页的渐清晰过程。

## 当前原型参数

| 进度/时间 | 当前效果 |
| --- | --- |
| 0% / 0ms | 上移、容器扩展、背景等比例缩放、周围/前景模糊同时开始 |
| 25% / 200ms | 原412×915画板中卡片中心从y718移到约y500，高度仅从180增至约231；先建立上移感 |
| 36% / 288ms | 周围模糊14px，前景文字/按钮主要模糊16px，背景仍清晰 |
| 40% / 320ms起 | 背景模糊、卡片淡出、目标页显现和清晰共用同一连续进度 |
| 55% / 440ms | 卡片中心到屏幕中心，继续展开及背景缩放 |
| 76% / 608ms | 容器覆盖画板，图片继续缩放；背景模糊与目标页清晰仍在同时进行 |
| 100% / 800ms | 背景图累计缩放1.82倍、模糊28px并退出；目标页模糊为0、透明度为1 |

后半段：`u = clamp((t - 0.4) / 0.6, 0, 1)`，`p = u² × (3 - 2u)`。背景图模糊为`28p`，卡片透明度为`1-p`，目标页透明度为`p`、模糊为`12(1-p)`。背景缩放独立持续，不能被模糊关键帧打断。

这些像素值来自412×915参考画板。复用时应根据真实卡片和视口推导起终点，不能直接固定y718/y457.5；保留800ms及动作关系作为基准，再结合具体场景审阅。

## 图片与交互约束

- 图片必须保持原始宽高比：等比例缩放并裁切，禁止只拉宽或只拉高。容器改变宽高不应拉伸图片；太阳等圆形应始终为圆形。
- 开始时锁定旧页面操作；目标页在过渡结束前不接收点击，结束后转移焦点。
- 重播、返回与Esc应取消旧动画，避免旧动画完成回调覆盖新状态。
- 减少动态效果模式采用现有160ms淡入淡出，省略明显位移、缩放和模糊。
- GIF前后700/900ms停留仅方便观看，不属于800ms转场，不添加到产品点击流程。

## 后续复用边界与验证

适合候选场景：从明确的内容卡片进入其详情或专注工作区，卡片与目标内容有清晰对应关系。作者只要求留作参考，具体复用位置逐项设计；不自动套用到所有点击、底栏切换或返回动作，不建立通用动效框架。

核对早段同时移动/缩放、中后段背景变模糊与目标页变清晰同步、终点可读可操作、图片不变形及取消/减少动态效果。原型通过这些时序检查不等于业务数据加载、真机性能和可访问性已验收。
