# 全流程原型的公共交互合同

日期：2026-10-17。适用范围见[完成清单](../../progress/nautilus-ui-flow-completion.md)。本文与共享Penpot第01—133组共同描述流程，不代表动态业务、视觉、响应式或真实用户验收完成。既有已确认产品决定优先；本次问答最初按授权代选，作者随后已明确确认；当前依据及原过程见[决定记录](../../progress/nautilus-product-design-decisions.md)。

## 入口、上下文与返回

五个一级入口沿首页、计划、学习室、学习库、我的。非沉浸页保留入口；学习室沉浸模式才隐藏，退出可恢复。R1—R9新增110张状态页共550个导航连接已接通；这些是新增绑定，不重跑旧页面检查。

进入子流程携带原入口、对象ID、所属计划/任务、对话类型及当前选择的版本。返回恢复该入口的筛选、排序、展开项和滚动位置。输入失败或返回不得悄悄改成另一对象；原对象不可用则显示具体原因并允许返回可用上层。原型的固定列表页不模拟任意数据持久化；业务完成写入后必须按返回结果刷新对应项，不展示旧状态或重复创建。

| 场景 | 复用部分 | 必须保留的差别 |
| --- | --- | --- |
| 普通学习对话 | 输入、附件、消息编辑/版本、生成恢复、模型/工具、分支 | 保留原任务/会话关系；普通删除仅移除所选对话，清除内容另走明确范围 |
| 题目讨论 | 上述适用组件、教法/帮助与纠正 | 固定原验证/提交/题目/评估版本；不创建正式新作答，不跳转普通对话；来源清除限制继续生效 |
| 老师对话 | 消息、附件、生成与工具边界 | 独立持续会话，模型/人格沿全局或自身；不跟随最近任务，不提供未支持的复制学习分支 |
| 规划对话 | 草稿、消息、来源与运行恢复 | 改的是规划草稿；只有明确采用才改变实际计划，不能把对话回复当作已采用 |

对话分类不改变上述用途和业务归属。当前类型不支持的操作不以一个共用菜单强行展示。长按、右键、拖动、真实输入与键盘操作仍须在实际UI中验证，Penpot固定点击示例不冒充手势验收。

## 普通表单与草稿

作者随后明确确认的设备内草稿合同：按当前用户、目标对象、表单类型及原版本隔离；普通编辑离开保留，刷新/应用重启后可继续，不跨设备同步。凭据不纳入普通草稿；既有明确即时保存项（如诊断启停）、笔记自动保存、思考滑块松开保存按其专门规则执行。

表单状态为已载入、编辑中、保存中、已保存、失败/结果未知、版本冲突。保存前显示实际影响范围；保存成功或本人明确放弃后清理对应草稿。切换对象不得串入旧草稿，恢复前核对对象/来源是否仍可访问。来源彻底清除须同时清理受管草稿，不通过本地缓存恢复被清除正文。未能核对来源状态时保留待恢复标记，先核对再呈现内容；不要把暂时离线当成清除成功。

字段按对应已确认业务合同及接口schema呈现：文本、数字、单选/多选、时区/日期、文件及动态服务字段各自校验。必填/空白错误就地说明；不静默截断正文、改选值、补造默认事实或丢弃用户输入。确有既定边界（如人格名60字、人格JSON64KB、Python预算）才显示相应限制，不能把模型窗口或旧工程常数变成新的产品字数门槛。

分类名称去首尾空白后不能为空，完全同名提示选择已有项；不自动合并近义词。重命名保持分类ID及关联，删除分类仅删该分类与关联，不删对话。其他页面/设备变更后先重新预览受影响对象。

## 异步运行、提交与恢复

- 请求接受前失败保留输入和本次配置；接受后冻结实际模型、人格、资料/帮助及业务版本，后续设置不回写旧运行。
- 排队、运行、取消请求中、已取消、失败、结果未知、成功分别显示。结果未知先读取同一请求状态；明确重试仍复用必要幂等标识，不把重复点击变成多份提交/分支/计划。
- 已保存作答不因评估失败重交；只重试该次评估。旧评估与新的评估分别保存，取消或晚到结果不覆盖另一对象/版本。出题失败不补造题目，等待仅有思考输出不冒充最终答案。
- 关闭窗口通常不等于取消已接受运行；具体取消须显式操作。Python、模型回答、复盘等依各自规则保留运行状态与返回入口。关闭自动归类后不得自动采用晚到归类结果。
- 无权限、来源已清除、加载失败、真正空列表、无结果、不支持能力分别显示。错误不冒充空结果；没有结果不补出分数、完成或掌握。
- 失败恢复不自动切换模型/提供方、不静默删输入、不重新外发已失效资料。需要改变范围/提供方/有成本测试时，先展示实际内容与目标，再由本人采取对应操作。

## 计划、验证与完成的字段复用

计划编辑沿第41—54组和D2合同：标题、任务/模块、目标/标准、依赖、日期/预算均为可编辑字段；AI只修改候选草稿，采用前展示实际变化。跨计划三选项及嵌套单层移除沿R2；确认时重查范围并原子处理，不用原型固定的6任务/2完成作为真实数据。

验证沿既有题目/材料提交流程：每次提交不可变且绑定当时标准/帮助条件；新版本不覆盖旧作答，反馈按所选提交/评估回看。讨论和补练不自动变成正式通过。原型固定选择只是代表样例，任意字段、未答、失败与恢复使用本合同。

执行完成分未验证、非AI验证附材料、外部报告未附材料。外部方式和本人报告结果必填，结果可以部分通过或未通过；有材料时名称/正文及作品或结果类型分别保存。仅有作品不能标作已有验证。AI材料审查及本人回应另存，不改外部原结果，不撤销既有执行完成；清除内容保留完成事实与来源类别。

## 对话查找与自动归类

首次列表默认全部对话、置顶前置及最近聊天排序；同一选定排序用于置顶与非置顶组，值相同时用稳定标识保持顺序。聊天时点来自已接受本人消息或已保存回复；改名、分类、复制继承历史不产生新聊天时间。时间范围表示区间内确有聊天，按查看时区含首尾日期；未来/无匹配显示空结果。当前设备记住筛选/排序，清除筛选恢复默认；学习库首次进入记录，之后记住该设备上次分类及查询状态。

AI归类首次默认关闭，明确核对可读取内容范围及提供方/模型后开启。会话结束或返回列表时只处理有新内容且未人工锁定的对象；同一内容版本去重。先复用已有分类；新分类及关联先审阅，可修改名称、选已有类别、逐条取消或暂不采用。人工纠正锁定，重新开启全局开关不解除锁定，须本人允许该对话继续AI整理。

每批保留原关联和实际采用差异。撤销最近自动处理只撤销该批新增/调整的关联，不删除对话、不删除已建分类、不覆盖后续人工修改；确认时发现版本变化就显示差异。撤销后同内容不立即再次自动归类，新增内容或本人主动整理才可再处理。关闭阻止新自动调用/采用，已有人工与已保存结果保持。此流程最初按授权代选，作者随后明确确认自动归类修正版；归类引擎尚未实施。

## 批量复核与综合成果

只对同成果、同标准版本、相近情境、同帮助与隐私范围、无冲突且建议一致的低风险主张批量处理。反面证据、不同条件及影响路线/委托/权限/费用的项单列。每条保持原始依据和独立审计，不合并成一条不可追溯证据。确认前核对全部所选对象；某项失效/变化则停止本次采用、返回差异，不把部分结果冒充全批成功。

撤销刚才的批处理先比对本批结果版本，逐条记录补偿处理并恢复处理前状态；若存在后续修改则先核对，不覆盖。这里撤销的是处理效果；已经撤回或替代的主张不能原地复活，纠正须关联新的主张。暂不处理不等于认可或拒绝，条件未变不重复打扰。

综合成果创建只新增对象；包含关系的起点必须为综合成果，不自关联、不成环；重复关系不重复写入。子成果覆盖不等于整体支持，不平均状态或迁移证据；整体协同/迁移要求独立依据。创建和选子成果的固定示例不宣称综合能力评估已实现。

## 高影响操作共用流程

共用顺序为明确入口 → 读取影响清单 → 本人确认目标及范围 → 确认时按版本/清单重新核对 → 原子处理或明确的逐项清理结果 → 返回当前真实状态。范围变化须重新展示，不让旧确认覆盖扩大后的影响。普通分类移除、对话软删除与彻底内容清除使用不同文案，不互相冒充。

| 清除对象 | 影响预览必须列出 | 保留/恢复边界 |
| --- | --- | --- |
| 资料 | 版本、原件、派生文字、引用/受管副本与普通备份 | 外部Obsidian原文/云端副本不属于本机可清除范围；部分失败可重试 |
| 验证 | 题目、全部作答/评估、关联或引用的讨论、依赖判断及受管副本 | 完成事实保留，依赖依据失效；不从旧讨论恢复题目正文 |
| 执行完成内容 | 说明、材料、记录时约定、后续审查/回应及副本 | 完成事实和来源类型保留，原文不可恢复 |
| 自动复盘 | 输入说明、候选/解释、受管内容副本 | 原学习事实和原件不连带删除 |
| 对话/老师的内容清除 | 明确该场景实际覆盖的正文、标题/派生内容及受管副本 | 普通删除不声称彻底擦除；存活分支/来源权限依原合同处理 |

清理进行中阻止旧生成结果回写；完成、部分失败、外部副本不受控分别呈现。只重试失败部分，不把删除成功的内容重新读取回来。权限、来源、历史保全及真实清理还须在业务实施时验证。

## 实施与验收边界

流程固定样例、共用契约和真实实现是三层：本轮完成前两层；代码、schema、真实AI/通知/搜索、计时采集、文件/图片存储及trial均未修改。已通过的旧证据按完成清单复用。实际UI开发应按同一对象/版本/返回上下文实现动态状态，不逐张复制固定状态样例；布局、视觉、响应式和动效仍需相应设计与实际用户验收。
