# E4 第一项：Python 代码运行

状态：作者确认首个能力及以下两项使用选择；第一片工程实现已完成，试用启用与检查以开发状态为准。不是完整 E4 平台或正式编程能力验证。

## 已确认的用户目标

- 先实现 Python／代码测试沙箱，能实际运行学习中的代码、查看输出和测试结果。
- 本人点击“运行”；AI可以提供代码和解释结果，但不自行执行。
- 支持 Python 标准库、NumPy、pandas、Matplotlib，暂不支持任意安装第三方包。
- 运行成功与正式学习达成分开，插件不扩大角色、资料或事实写入权限。

## 本片交互

普通学习室和题目讨论的已完成 Python 代码块显示“运行代码”。点击打开编辑与结果窗口，可改代码和标准输入；改动不覆盖原回答。首次明确“启用并运行”，之后“运行”。设置的“扩展能力”中可停用或调整等待/内存预算。提供取消、运行记录选择及恢复当次代码；关闭窗口不取消已接受的运行，刷新后可继续查看。

结果展示 stdout、stderr 和 PNG 图表；代码异常、超时、取消、运行环境不可用、来源清除、服务中断各有明确状态。每次独立运行，不保留上一轮 Python 变量。可“复制代码与结果”后由本人粘贴到下一条消息请 AI 分析，不自动发送结果或调用 AI。继承的历史回答第一片只读，不新增运行入口。

## 架构与执行

复用 AgentRuntime 的本人身份/审计边界、现有回答运行快照、鉴权、来源清除与备份流程。PythonExecution 为单一已登记能力，HTTP入口仅接受本人操作，不声明给模型的函数工具。原搜索/知识库/解析运行时保持，不为插件外观重做它们。

每次运行冻结代码、标准输入、原回答位置、实际镜像ID、库版本和资源预算。`python_runs`作为附属运行记录放入当前回答现有快照；不更改冻结的模型参数、不新建学习事实/教学记录/帮助/证据，不复制第二套学习历史。原来源清除会清除其运行副本及受管理备份；执行中轮询复查，保存结果前再次核对，禁止清除后回写。普通软删除对话沿既有规则禁止再访问，不冒充彻底擦除。

执行使用独立 Docker 容器：固定非root身份、只读根、无网络、无主机挂载/环境继承/宿主Docker接口，丢弃capabilities及新增权限；采用Docker默认seccomp。一个本人同时一项运行。默认30秒/512MiB，等待可调1–300秒，内存可选128/256/512/1024MiB；1CPU、64进程、64MiB临时工作区，无额外swap。这些是执行资源预算，不静默裁剪代码或文本输出。结果收取按当前主机内存检查、临时缓冲，PNG解码验证后展示。预算调整只用于之后运行；停用取消已在执行的任务。

镜像由Linux/CPython3.12主机解释器、标准库、必要共享库及固定科学计算wheel构建，不复制用户主目录、项目或配置。此环境镜像仓库连接失败，采用本机专用构建，未通过第三方镜像源或削弱隔离解决。构建/运行说明见[沙箱说明](../../../backend/sandbox/README.md)。容器共享主机内核，第一片用于当前本人开发试用；不宣称公开多租户的强隔离服务。

服务正常停止取消运行；重启仅清理本数据库标签下的残留容器，待处理记录标为中断，已完成记录保留。无数据库迁移。
