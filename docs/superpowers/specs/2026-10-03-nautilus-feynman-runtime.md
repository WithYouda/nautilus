# 费曼复述运行时首片

日期：2026-10-03。作者已确认同时提供单次复述活动和设置页的持续费曼方式，已在原trial039启用。工程检查通过，当前真实模型多次漏回状态，复述记录可靠性仍未达标。实际检查、启用状态及限制见[开发状态](../../progress/nautilus-development-status.md)。沿PRD V2、[产品决定9.5](../../progress/nautilus-product-design-decisions.md#95-苏格拉底模式是协议不是-prompt)与路线C2，复用当前教学运行时，不新增正式学习证据。

## 确认的交互

- 单次活动放在折叠学习安排中，已有小点时可点“用自己的话说说”。AI只邀请复述并等待，用户实际复述后说明已讲清和最值得补充的地方；可继续补充，或“继续学习”恢复原小点及基础方式。点击保留草稿，动作本身不是尝试。
- 持续入口为“设置 → 默认学习方式 → 费曼复述”，不在每次回复下添加模式按钮。每个小点先邀请用户解释；反馈后等待补充，不擅自推进；“继续学习”可进入后续小点。自然改变主题仍遵从用户请求。
- 用户可随时请求提示、当前步骤解释、直接答案或完整讲解，不强迫复述；明确临时请求仅本轮，明确持续表达才改变当前路径，不能改个人默认。
- 两处对话均可在默认折叠的“复述记录”回看原小点、复述原话与AI反馈，复用尝试纠正。AI观察不代表评分、通过或掌握，不写031补练、正式验证提交/评估、证据或成果状态。

## 默认与冻结

个人设置增加`teaching_mode: stepwise | socratic | feynman`，复用本人加密设置存储。旧设置缺字段按分步；旧客户端PUT省略字段时保留已有默认。验证失败或保存失败不覆盖原设置，无数据库迁移。

检查点`mode_source`区分`default`和`conversation`。未单独调整的路径在新请求接收时读取当时默认；学习安排已有分步/提问引导覆盖和明确持续自然请求优先，`teaching_mode=default`恢复沿用设置。旧记录缺来源时，历史存在明确选择/持续请求或非分步基础方式则保留路径覆盖，否则沿用默认；不改历史快照。持续费曼通过设置启用，学习安排不新增可选费曼项。

两路发送在接受时冻结`default_mode`、明确选择与动作。设置变化不改已接受请求或幂等重试，重生成沿原请求冻结默认；编辑/新消息从其祖先重新冻结。取消或失败保持已接受的明确选择和原教学位置。

## 状态与来源

教学协议v4兼容v1–v3。请求新增`teaching_action=retell`，与`practice / continue`共用冻结和幂等边界。

1. 单次复述复用现有`practice`活动框架，增加`kind=retelling`；变式为`variant`，旧缺kind按变式读取。活动保存原小点、返回提示安排、邀请回答与Unicode码点范围、等待/已有反馈状态。活动中不转小点，结束恢复原位置；更改基础方式沿原重置规则。
2. 持续费曼的检查点增加`retelling`，保存当前小点、等待复述/已有反馈及最近反馈来源。只有实际本轮尝试与正常完成的合法状态提案才登记反馈；实际复述或帮助请求不能同时擅自转到新小点。无尝试、截断、取消或无效提案不补造反馈/进展。
3. 单次活动沿`practice_observation`引用邀请、用户原话与逐字反馈；持续方式用`retelling_observation`引用原小点、用户原话与本轮完整反馈正文。二者均冻结提交前路径上实际已提供/客户端报告展示的帮助事实，不冒充已阅读或独立完成。后续纠正改变观察可用性，旧正文/冻结条件保留。
4. 仍由一次模型调用同时生成正文和教学提案，不增加二次识别或修复调用。复述运行上下文提供本轮精确状态尾示例，降低模型只给正文的遗漏；模型不遵从时仍保留正文和实际帮助、记录脱敏失败原因，不能凭正文猜造状态。
5. 正文保存在原消息，快照只存来源ID和跨度；提示需邀请原文时从已允许路径临时解引用。分支映射本地步骤/邀请/作答/反馈/帮助来源，保留原始来源；严格资料范围、清除与受管理备份沿现有依赖闭包处理，不重新引入已清除内容。

## 验证边界

覆盖设置兼容与本人隔离、失败保留、默认/覆盖/恢复默认、接受后变化/重生成、两种复述/帮助/纠正、版本与分支、截断/取消、范围与备份清除、旧协议和正式事实不变。浏览器覆盖两处学习室、设置位置、草稿、失败重试、刷新、窄屏与记录回看。实际模型检查只使用合成学习内容，不能当成所有模型的长期可靠性或学习效果证明。

下一项先处理真实模型状态尾缺失的可靠性，禁止从正文猜造尝试；之后再按C2核清练习优先、项目实践、自适应以及普通教学观察进入正式验证的边界，不启动C3或客户端。
