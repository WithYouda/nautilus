# Nautilus 对话管理与标题呈现修复设计

| 项目 | 内容 |
| --- | --- |
| 日期 | 2026-08-03 |
| 状态 | 用户已确认，已实现并完成隔离验收 |
| 适用范围 | AI 学习室外层工具区、对话历史内联管理、对话软删除、标题生成兼容性、标题栏信息层级 |
| 数据库迁移 | 无；复用 `conversation.deleted_at` 与 `008` 标题版本字段 |

## 1. 目标

- “当前对话信息”入口不再侵入消息阅读区域，改到学习室外层工具区并紧邻“对话历史”。
- 对话历史浮层支持切换、手动改名和带确认的软删除。
- 对话标题在聊天标题栏正中显示，顶部不再常驻机器人图标、回答状态或标题生成状态。
- 修复推理模型标题请求输出预算过小导致只返回推理、没有最终标题的问题。

## 2. 外层工具区

桌面与移动端统一按以下顺序排列：

```text
对话历史 / 当前对话信息 / 对话配置 / AI 提供方设置 / 新建对话
```

“当前对话信息”浮层继续展示任务完整路径、状态、截止日期和进度；独立对话明确显示未关联任务。入口与浮层不得位于 `.ai-room-chat` 内，也不得改变消息区宽高。浮层继续支持点击外部、焦点离开和 Escape 关闭。

## 3. 历史内联管理

每条历史记录由三个独立操作区组成：

- 主区域点击后切换对话。
- 编辑图标进入内联标题输入；Enter 保存，Escape 取消。
- 删除图标打开确认弹窗，不允许单击后立即删除。

手动改名写入后端，设置 `title_source=manual`、`title_generation_status=idle` 并增加 `title_revision`。同时把尚未完成的旧 Title Run 标记为 `superseded`，保证晚到结果不能覆盖用户标题。

删除使用 `conversation.deleted_at` 软删除。活动 Chat Run 存在时拒绝删除并要求先取消生成。删除当前对话后，任务入口优先恢复同一任务最近的有效对话；没有候选时回到该任务的新空白对话。删除非当前对话不改变当前阅读位置。

## 4. 标题栏与运行状态

聊天标题栏只显示一行居中标题。删除顶部机器人图标、“回答完成”“可以开始提问”、重连计数和“正在整理标题”等常驻状态。

必要运行反馈保留在已有位置：流式消息本身、取消生成按钮、错误提示和重新发送入口。标题生成状态仍可在对话配置浮层中查看，不占用标题栏。

## 5. 标题生成修复

首问生成的本地标题继续作为即时兜底，但首轮成功回答后的 Title Run 必须有机会覆盖它。

当前失败元数据显示，Title Run 已启动，但提供方非流式响应没有最终正文。现有 `max_tokens=48` 对推理模型过小，可能全部消耗在 `reasoning_content`。本轮提高标题请求输出预算，同时保留 30 秒超时和 32 字最终规范化限制。若提供方仍只返回推理而无正文，记录明确的协议错误，不把推理过程直接用作标题。

前端在主回答成功后对 `pending/queued/running` 都提供短暂轮询宽限，避免 Title Run 入队与对话重新读取之间的竞态。

## 6. API

新增：

```text
PATCH /api/ai/conversations/{conversation_id}
  请求：{ "title": "..." }
  返回更新后的对话详情

DELETE /api/ai/conversations/{conversation_id}
  204 No Content
  活动 Chat Run 存在时返回 409
```

不新增迁移，不物理删除消息、运行、上下文快照或任务关联。

## 7. 验收

- 改名持久化，刷新和切换后仍显示手动标题，旧 Title Run 不会覆盖。
- 删除前必有确认弹窗；取消不删除，确认后历史列表和详情 API 都不可再读取该对话。
- 删除当前对话后恢复规则正确；生成中的对话不能删除。
- “当前对话信息”按钮位于外层工具区、紧邻历史按钮，聊天画布内不存在该入口。
- 标题中心与聊天区域中心对齐，标题栏不存在 `.ai-status`。
- 推理模型在较大标题输出预算下能返回最终标题；只返回推理时错误信息明确。
- `1440x1000`、`1024x640`、`390x844` 无页面级溢出，消息区仍占主要空间。
