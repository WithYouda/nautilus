# 教学记录的结构化输出

日期：2026-10-03。作者已确认：有状态教学使用已检查支持的原生结构化输出；未检查或不支持的模型保留普通聊天，并说明教学记录不可用。本文替代C1/C2早期契约中的正文状态尾传输方案，其余教学、来源、纠正和正式证据边界继续适用。实际检查及启用状态见[开发状态](../../progress/nautilus-development-status.md)。

## 能力检查与兼容

- “设置 → 学习方式 → 教学记录”默认折叠，选择模型后可检查支持。检查只发送两次简短合成内容，分别测试普通流式回复和带外部工具声明的流式回复，不使用用户对话内容、不改默认模型。
- 当前能力契约为version 4，覆盖adaptation及learning对象；旧version 1/2/3结果须重新检查，已接受运行与历史记录不变。
- 检查结果保存在模型现有能力字段，绑定提供方配置版本、凭据版本、协议和模型名。相关配置变化后回到未检查；网络、超时、鉴权等临时失败保留此前结果；明确拒绝请求或格式不合约时该组合不可用。
- 普通对话与外部搜索/知识库组合分别判断。模型内置搜索的原生轮次和引用尚未验证，本片保持普通聊天并提示当前联网方式不能记录教学状态，不隐式关闭搜索或更换模型。
- 请求接受时冻结输出格式和能力绑定；已接受请求的幂等重放不重新判断。重新生成是新运行，读取当前实际模型/配置的检查结果，教学默认和原动作仍沿既有冻结规则。
- 不可记录时不注入教学记录协议；显式练习、复述和继续活动在写入消息前拒绝，普通输入与既有帮助入口可继续。旧记录仍可回看，不能从旧正文补造新状态。

## 同次输出与流式呈现

结构化传输自教学协议v5引入；当前v9兼容v1–v8，新增教学语义见[练习优先契约](2026-10-03-nautilus-practice-first-runtime.md)、[项目实践契约](2026-10-04-nautilus-project-runtime.md)、[个人自适应契约](2026-10-04-nautilus-adaptive-runtime.md)及[细粒度学习情况契约](2026-10-04-nautilus-learning-observations.md)。受支持请求的最终输出为一个对象：`{reply, teaching, token}`。`reply`是用户可见的Markdown正文；`teaching`保持`step / attempt / mode / help / practice / project / adaptation / learning`语义；`token`与本轮服务端冻结值一致。仍只用原教学调用，不增加每轮识别、修复或分类调用；原有标题和已授权工具续答沿原流程。

四协议使用各自原生请求参数：Chat的`response_format`、Responses的`text.format`、Google的`responseMimeType`、Anthropic的`output_config.format`。请求约束不等于语义正确，完成信号、逐字原文引用、活动与步骤转换仍由应用校验。

流式解码只向正文、SSE和生成轨迹输出`reply`字符串。跨块转义、换行、Unicode码点和字面`<think>`按原文解码；仅提供方明确的原生思考字段进入思考流。元数据有16,384字符边界，正文不在解码器内额外累积。未知/重复字段、错误token、损坏或未完整结束的对象不能提交教学状态，已解码的部分正文继续保存。正常结束且原状态校验成功，才与完整回答同事务采用。

外部工具每个模型轮次单独解码；最终无工具调用轮的合法提案才有采用权。工具前实际出现的正文仍保留，但新步骤、题目和反馈只能引用最终轮正文，保存时换算为完整回答的Unicode码点范围。运行上下文仍在真实本轮用户消息之前，图片归属和本轮用户原文不变。

原生工具输出和签名继续原样保存。同协议、模型、地址及输出格式时按原规则回放；JSON、旧状态尾和普通文本之间切换时，使用已保存的公开正文作为历史输入，不把旧JSON对象塞入普通聊天，也不改写原生签名块。本片不宣称覆盖所有网关在系统提示、工具、历史截断变化时的签名兼容性。

## 不变边界与检查

教学记录仍是可纠正观察，不是正式作答、评分、独立完成或掌握证据。来源ID、原文跨度、帮助条件、分支、严格资料范围和清除沿原契约；不新增数据库表、迁移或依赖，不自动改变用户的学习方式。

重点检查：增量解码与错误保留、四协议普通/工具参数及原生历史、能力过期与临时失败、两处实际对话及逐字反馈、重试/重生成冻结、最终工具轮来源范围、设置/窄屏/记录回看。真实模型合成样本只证明该配置下的实际结果，不替代其他模型和组合的检查，也不证明长期教学效果。

接口依据：[DeepSeek JSON模式](https://api-docs.deepseek.com/guides/json_mode/)与[Anthropic结构化输出](https://platform.claude.com/docs/en/build-with-claude/structured-outputs)。原生约束仍可能截断、返回空结果或产生语义无效内容，沿现有失败边界处理。
