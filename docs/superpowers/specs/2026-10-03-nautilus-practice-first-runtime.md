# 练习优先运行时首片

日期：2026-10-03。作者明确选择“采用，点‘下一题’才继续”。遵循PRD V2、[产品决定9.4–9.5](../../progress/nautilus-product-design-decisions.md#94-学习模式)及路线C2；实际检查与启用状态统一见[开发状态](../../progress/nautilus-development-status.md)。

## 已确认流程

- 在“设置 → 默认学习方式”选择“练习优先”。沿已有个人默认/当前路径覆盖规则，新请求读取默认，已接受请求、重试与历史不改；重新生成保留原学习方式和动作。
- 主题明确后先出一道题，等待用户作答，不预先给解法。信息不足先澄清，不造题目或尝试。
- 依据真实作答反馈后停留，可补充作答、提问、求助或直接看讲解。只有点“下一题”才出下一道，也可未作答直接跳过；不在反馈后自动接题。
- 默认折叠的练习记录保存原题、作答原话及AI反馈，识别可纠正，原话及历史版本保持。临时单次复述优先，结束后回到同一道题；取消下一题生成时保留原题及已产生的部分正文。
- 普通练习与正式验证分开。现有“进入验证”和开始/提交/评估流程保留，不自动开始验证、不改写正式结果，也不把聊天练习作为031补练的原正式提交。

## 运行状态与来源

协议`teaching-v6`兼容v1–v5。新增基础方式`practice_first`与明确动作`next_question`，传输仍按[结构化输出契约](2026-10-03-nautilus-teaching-output.md)，不增加识别或修复调用。

当前检查点的`exercise`保存题目回答ID、完整题目的Unicode码点范围、等待作答/已有反馈状态和最近观察ID。首题和下一题都由同次提案的`practice.question`逐字引用正文，`step/attempt`保持null；Runtime建立对应当前题目，不让模型自填ID或完成结果。`exercise_question`保存本轮新题来源，`exercise_observation`关联原题、真实用户作答、逐字反馈和作答前已发生的帮助事实。

已有题目时，真实作答须有反馈引用；点击下一题、普通提问、说懂了和求助不算作答。未点击下一题的换题提案、通过step更换当前题目、错误引用或非正常完成均不推进。临时直接解释仍针对原题；基础方式明确切换后沿原路径规则生效，不改变个人默认。临时练习优先请求只作用本轮，题目及后续真实作答仍可关联，反馈后回到原基础方式。

连续题目与单次`practice`活动分开保存，单次复述/变式可暂时借用当前题目作为原小点；继续学习恢复原题，不能把复述邀请误当下一题。分支映射题目、作答、反馈及帮助来源ID；严格范围校验和来源清除沿原依赖闭包，快照只新增引用与跨度，不复制私文。外部工具最终轮正文偏移同样覆盖新题及反馈。

## 首片边界

不评分、不认定完成或掌握，不按题数或模型判断自动调整正式计划、成果或验证标准。针对性补练仍要求具体正式题目/提交/评估来源；普通教学观察导入正式验证的标准与帮助映射继续后续核清，不在本片绕过。无新增表、迁移或依赖。

重点检查两处对话的首题/反馈/下一题、跳过、求助、单次复述恢复、草稿、取消/截断、原文与纠正、设置/版本冻结、分支/范围/清除，以及正式记录不变。真实模型只使用合成内容检验实际流式输出，不把工程检查等同于所有模型表现或长期学习效果。
