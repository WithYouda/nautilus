# E1 分支比较与结论

2026-10-07。依据原设计3.4、当前PRD V2、产品决定与作者本次两项确认。

## 用户流程

分支图保留默认折叠、缩放、平移及编辑标题。“合并对话”入口要求本人明确选择同图内两个可用对话，两个选择初始均为空，不自动选择共同起点。只读取各自当前选中的祖先路径，不混入其他回答版本或后续内容。显示两条路径的末端问题，主动整理合并内容；AI返回有原文依据的观点卡片，本人勾选、编辑并填写合并后的主题后，创建新对话并打开。

新节点位于两个实际来源之后，两条同义入边直接汇入节点；任一来源不可用时显示失效入口，不将合并边改接祖先。原始对话及关系不变，不做文本逐字Diff、跨图拼接或拖拽改写真实血缘。普通学习室和题目讨论保存仍在原类型中，题目讨论保持同一题目/提交/评估归属。

打开合并后对话时，顶部以“合并对话”、两个可返回原位置的来源、可折叠的保留内容呈现新起点；不把内部结论种子呈现为系统代写的用户问题和普通AI回复。继续提问后自动折叠，随时可再展开。旧合并仅更新显示，原正文/来源不凭新期待回写；先前误选来源应由本人重新选择后创建。

完全相同的所选对话文本直接提示无新增内容，不调用Provider；模型也可返回空卡片表示没有值得保留的新内容。空结果不给可保存预览，不创建对话，不把无法比较或补充方向说明当作结论。语义上的有效内容仍由模型整理、本人审阅；不宣称可确定性排除全部无意义生成。

## 实现与事实边界

- 比较是按需预览，不自动执行工具、联网、写学习事实或切换主线。使用发起对话的实际模型/超时配置及共享Provider并发槽，保存实际模型快照。
- 预览仅在当前界面保留，关闭或刷新后可重新生成；服务端短期缓存只保留ID、校验摘要和模型配置，不额外保存比较正文。输入过大或输出不符合结构时明确失败，不静默截断内容或编造来源。
- 保存新结论复用现有对话、消息/讨论轮次与运行快照，不建立第二套聊天或教学状态。首条明确标记为经本人整理确认的结论；不会自动合并教学观察、掌握状态、正式证据或原评分。
- 新节点从所选结论继续，不复制两条分支全部正文作为新的聊天记录。来源保留准确回答ID及路径依赖，引用可以回到原位置。继续对话沿用发起分支的模型选择与任务归属；人格按该任务的现行规则处理。
- 预览后保存再次核对原路径内容与可用性；来源删除、清除或变化时拒绝采用旧预览。保存幂等，重试不重复创建节点。
- 资料/题目/来源清除覆盖比较结论与其继续对话、分支副本、受管理备份，沿既有依赖和恢复屏障；图只保留必要ID拓扑，不残留私文标题/引用。预览结果不自动成为学习成果或验证通过。

## 关键验收

两类对话各自完成：分支→比较→来源引用→勾选编辑→新结论→继续问答；原对话/评估不变，其他版本不混入。同图/所有权检查、清除竞态与依赖传递、重复保存、失败后重试有效。桌面与390px可操作；沿用既有分支图检查并验证新增双来源连线。通过后在原trial049启用，无新迁移则正常重启即可。朗读不实施，后续核对E4。
