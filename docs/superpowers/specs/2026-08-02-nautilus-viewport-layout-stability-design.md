# Nautilus 视口布局稳定性修复设计

| 项目 | 内容 |
| --- | --- |
| 日期 | 2026-08-02 |
| 状态 | 用户已确认，已实现并完成隔离验收 |
| 权威边界 | 服从 `2026-07-23-nautilus-design.md` 与用户最新反馈 |
| 实施范围 | 番茄钟浮层、工作区滚动模型、响应式视口、AI 学习室宽高、工作区背景 |

## 1. 修复目标

本轮只解决五个已复现的界面问题：

1. 活动番茄钟恢复历史拖动位置后可能跑出当前工作区，并扩大页面宽高。
2. 桌面三栏被中间长内容共同撑高，左栏和右栏不能稳定固定在当前视口。
3. 页面使用 `min-height: 100vh` 和文档级滚动，设备可用高度变化后会出现不必要的下滑与底部空白。
4. AI 学习室被固定最大宽度限制，桌面两侧留白过多。
5. 当前大面积青绿色背景不符合用户偏好。

本轮不新增业务功能、数据库迁移、知识库入口或新的视觉装饰系统。

## 2. 已复现根因

在 `1440x1000` 真实 production preview 中，将现有计时器历史位置设为 `{x:2400,y:3600}` 后：

- 浮窗实际移动到约 `x=2603,y=4698`；
- 中栏滚动尺寸被扩大到约 `2626x4766`；
- 页面文档高度从视口的 `1000px` 增至约 `1166px`。

原因是当前实现将相对旧中栏的像素坐标永久写入 `localStorage`，但刷新、栏宽调整、缩放和设备变化时不重新校正；同时浮窗使用中栏内的绝对定位，会参与该滚动容器的溢出尺寸计算。

AI 学习室当前被 `width: min(1040px, calc(100% - 72px))` 限制；在 `1440px` 视口中左右合计固定空出约 `400px`。

## 3. 已确认设计

### 3.1 番茄钟：B 受控拖动

- 保留桌面端拖动、最小化、隐藏、暂停/继续和结束操作。
- 使用 Portal 挂载到 `document.body`，采用 `position: fixed`；浮窗不再属于中栏滚动内容，也不能扩大文档尺寸。
- 工作区向浮窗提供当前中栏的真实 `DOMRect` 作为可拖动边界。
- 不再持久化未经解释的绝对像素；保存浮窗在“可移动空间”中的归一化横纵比例。
- 首次渲染、刷新、窗口缩放、浏览器缩放、左右栏拖动、横竖屏变化及浮窗尺寸变化时，都重新计算并钳制位置。
- 旧版 `nautilus.v6.timer-position` 像素状态只用于一次兼容读取；无效或越界值自动归位并覆写为新格式。
- 桌面安全边距为 `12px`，顶部避开应用栏；移动端不允许自由拖动，固定为底部安全区紧凑条。

### 3.2 工作区：固定视口壳层

- 桌面和横屏平板工作区使用 `height: 100dvh`，并以 `100vh` 作为旧浏览器回退。
- 根工作区禁止文档级溢出；左导航和右侧 AI 学习伙伴固定占满当前视口高度。
- 只有中间主工作内容纵向滚动；三栏不再被中间内容共同撑高。
- 左右栏内容优先压缩和固定底部操作；只有在极短视口确实无法容纳时，栏内内容区才出现局部滚动，不制造页面底部空白。
- 栅格子项统一设置 `min-height: 0`、`min-width: 0`，防止内容的最小尺寸反向撑大整个壳层。

### 3.3 响应式：按可用视口，不嗅探设备型号

- 不读取设备品牌或型号；依据 CSS 媒体查询、`window.visualViewport`、容器真实尺寸、横竖屏和安全区响应。
- `>1180px`：完整三栏；`761–1180px`：收窄导航并隐藏右侧伙伴栏；`<=760px`：单一页面流和导航抽屉。
- 移动端使用 `100dvh` 与 `env(safe-area-inset-*)`，处理浏览器地址栏变化和异形屏安全区。
- 普通页面只在内容真实超出时滚动，不保留人为填充的尾部空白。
- AI 学习室在各视口内保持输入区可见，对话消息列表独立滚动。

### 3.4 AI 学习室：铺满可用空间

- 移除 `1040px` 外层最大宽度，桌面仅保留 `20–24px` 安全边距，移动端保留 `12px`。
- 学习室外层填满应用栏下方的剩余动态视口高度。
- 上下文条、对话面板和输入区横向铺满；消息气泡仍限制可读行长，避免超宽屏上一行文字过长。
- 对话列表成为唯一主要纵向滚动区；页面本身不因消息增长无限变长。

### 3.5 视觉：B 岩砂航海日志

- 主背景：浅岩砂 `#EEE9DF`。
- 主导航：炭灰 `#273039`。
- 关键操作：铁锈红 `#B7553F`。
- 内容纸面：浅纸白 `#F8F4EB`；右侧栏使用略深岩砂层级。
- 背景只使用低对比度、细密纸张颗粒，不使用青绿色大色块、同心圆或装饰性渐变。
- 保留现有信息层级和功能语义，不重新制作 V7 视觉稿。

## 5. 回归与真实验收

自动化至少覆盖：

1. 注入极端旧像素坐标后，浮窗仍在中栏边界内，文档宽高不因浮窗扩大。
2. 拖动浮窗后改变左右栏宽度和视口，浮窗自动重新钳制。
3. 桌面三栏高度等于动态视口，只有中栏可滚动，左右栏位置不随中栏滚动变化。
4. `1440x1000`、`1024x900`、`390x844` 均无页面级横向溢出或无意义尾部空白。
5. AI 学习室在桌面占用至少 95% 可用主栏宽度，消息列表独立滚动，输入区仍在视口内。

实现后必须真实查看上述三个视口的首页、活动计时状态和 AI 学习室截图，并记录浏览器控制台错误、请求失败和滚动尺寸。

## 6. 完成标准

- 番茄钟在任何已覆盖的缩放、刷新、栏宽和设备变化后都不会离开允许区域或拉长页面。
- 桌面左右栏在中栏滚动时保持固定，页面底部没有由壳层高度错误产生的大块空白。
- 移动端无需横向拖动页面，内容只在真实超出时纵向滚动。
- AI 学习室明显铺满可用空间，同时保持消息阅读宽度合理。
- 页面不再以青绿色作为主背景。
