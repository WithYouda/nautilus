### 切片 1：最小访问与恢复安全修补

**覆盖**：`REVIEW-001`、`REVIEW-002`、`REVIEW-003`。

- 用户问题：能连接本地服务的客户端不能因此自动获得作者身份；彻底删除过的内容不能通过受控恢复链重新出现。
- 最小范围：停止未认证 API 返回可直接授权的秘密；复用可信本地渠道完成首次授权；受控恢复不得丢失当前已知 purge/tombstone 屏障，不能证明安全时拒绝；文档明确当前删除/备份/恢复实际保证。
- 不包含：云账号、多用户权限系统、双库合并、旧私文真实迁移、全磁盘/Provider副本清理或自动重写全部备份。
- 前置依赖：作者确认正式支持的网络信任范围；若要收窄已确认的彻底删除承诺，须单独确认。禁止越权和禁止受控恢复复活已删内容本身不重新决策。
- 验收：无Cookie客户端不能“取码后自行授权”；可信本地授权仍可用；合成的“删除后状态 → 缺对象旧备份 → 含旧正文备份”两步恢复被阻止；合法的删除后备份仍可恢复；拒绝恢复不改变当前库。

### 切片 2：可靠、可解释的回来继续学

**覆盖**：`REVIEW-004`、`REVIEW-005`，并继续 Task 13B 真实使用基线。

- 用户问题：用户回来时应能继续学习并理解为什么做这一步，不能因为指标接口故障失去首页。
- 最小范围：指标加载与核心学习状态/返回卡分离；实际显示已有规则推荐理由；继续复用现有中断恢复、验证回看、原计划追加和完成语义。
- 不包含：新推荐模型、完整成果图/路径图、自适应长期排期、目标正式收尾、整体前端重构或新指标平台。
- 前置依赖：无 Task15/16/17B/19/20 硬依赖。
- 工程验收：指标接口失败仍能创建/继续；中断与已保存验证恢复到正确委托；推荐理由与实际跳转一致；本次完成不变成目标完成或稳定掌握。
- 真实使用证据：作者自然跨日/中断回来时，能从产品中理解上次位置、依据/未知和下一步理由并实际选择行动；无样本、窗口未满继续按既有口径单列。

### 切片 3：用户主动触发的真实联网搜索

**覆盖**：既有 `FOLLOWUP-SEARCH-001`。

- 用户问题：教学/验证需要真实外部资料时，不应依赖模型声称已搜索或离开学习流程手工搬运。
- 最小范围：单一明确搜索服务的配置、启停、连接测试；用户可见查询内容并主动触发；展示实际来源、检索时间与执行状态；失败时学习和作答仍可保存。
- 不包含：自主Research Agent、任意网页爬取、后台浏览、向量库、通用插件平台或默认发送整段学习正文。
- 前置依赖：作者确认供应商、预算和允许出站的信息范围；不以完整Task13B、成果图、路径图或人格系统为硬阻塞。
- 验收：关闭时不出站；失败/超时/未配置明确降级；不静默换服务；Mock之外完成一次经授权的真实搜索，不能以模型生成URL替代。

通用文件上传和目标正式收尾不自动进入上述三个切片：文件能力等真实材料场景明确后再做一个最小完整格式链；目标收尾等作者实际遇到“达成/停止/放弃跟踪”场景后再确定语义，不能用所有任务完成直接替代目标完成。

## FOLLOWUP-SEARCH-001：额外联网搜索服务配置与最小接入

**状态：已由用户明确要求纳入后续开发计划；尚未实现，不在本次验证入口修复中顺带开通。** 本条来自 2026-09-22 真实试用对联网能力的需求，不依赖 Task 15/16、完整 Research Agent 或通用插件平台。

- 用户问题：使用 DeepSeek 教学/验证时需要真实检索资料，不能把官网功能或模型声称已搜索当成应用实际能力。
- 最小范围：独立搜索服务的选择、地址/必要凭据配置、启停、连接测试；教学模型可继续使用 DeepSeek。默认不自动搜索，先明确发送给搜索服务的查询内容及使用边界。

### Task 17A：回归教练视图与自适应承诺窗口

**覆盖**：`CAP-FUT-001`、PRD V2 第 1.2、4.1、4.3、8.4 节和产品决策记录第 13 章

**依赖**：完整路径图版本可以使用 Task 16 的路线数据，但最小返回视图、现有返回卡修补和真实连续性验证不依赖 Task 15/16。自适应承诺窗口与返回视图分开验收，不因两者同属 Task17A 而互相阻塞。

**工作内容**：

- 实现默认回归教练视图：用户回来时能看到当前位置、已有证据支持的成果、未知和缺口、下一步推荐及理由，并能进入下一步行动。
- 提供恢复原委托、选择其他行动或查看依据的入口。
- 推荐必须能追溯到状态、事件、证据和规则，不能只来自模型偏好。
- 未授权原文、摘要和引用不得进入视图或 Agent 上下文。
- 实现最小自适应承诺窗口：初期只承诺少量学习会话，随真实执行、证据和节奏信号逐步扩展；不输出虚假的长期精确排期。
- 推荐或窗口调整不得自动修改正式计划、目标、路径或长期状态。

**完成标准**：

- 用户中断后重新进入时，默认视图满足 PRD 1.2 核心承诺；
- 下一步推荐、理由、证据缺口和权限边界可测试；
- 自适应承诺窗口只基于真实信号，不伪装成精确预测；
- 用户选择、确认和恢复路径可审计。

### Task 17B：主动后台教练

**覆盖**：`CAP-FUT-001`

### Task 18：模型策略层级与运行配置冻结

**覆盖**：PRD V2 第 7.5 节

**依赖**：完整的策略层级用户体验可以后置；单次运行配置快照、冻结与可追溯是可独立工程能力，不以 Task17B 主动后台教练为硬依赖。

**工作内容**：

### Task 19：人格 Profile 与学习模式最小闭环

**覆盖**：PRD V2 第 7.5 节

**依赖**：Task 18。

### Task 20：知识包与能力插件治理最小边界

**覆盖**：PRD V2 第 3.5、8.5 节

**依赖**：知识包的数据治理与可执行能力插件治理可拆分。插件仍服从统一Runtime、权限和沙箱；二者都不因人格 Profile 尚未实现而天然被 Task19 阻塞。

**工作内容**：

- 建立知识包版本、来源、适用范围、限制、争议和未知的审查模型。
- 建立能力插件的显式登记、权限、沙箱、预算、失败路径和审计边界。
- 知识包只声明领域数据，不包含任意执行代码。
- 能力插件由统一 Agent Runtime 装配和授权，不创建另一套运行模式。
- 不引入 Web Search、开放网络 Agent、社区市场或通用插件平台。

**完成标准**：

- 知识包和插件职责分离；
- 版本、来源、权限、审计和失败路径可测试；
- 包外 AI 推断只能作为候选假设，不能升级为事实或硬前置。
