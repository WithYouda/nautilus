# 首个窄领域候选方案

| 方案 | 领域 | 主要来源 | 优点 | 限制 | 建议 |
| --- | --- | --- | --- | --- | --- |
| A | Python 正则表达式基础 | Python 官方 `re` 文档 | 范围窄、语法明确、可做确定性验证、与当前技术语境一致 | 不代表通用编程能力 | **推荐** |
| B | SQL `SELECT` 基础 | SQLite 官方文档 | 查询语义清晰、可做确定性验证、实用性强 | 容易扩展到过宽的 SQL 范围 | 备选 |
| C | Git 分支基础 | Git 官方文档 | 操作路径清晰、适合实践型学习 | 验证更容易依赖命令结果而非语义解释 | 备选 |

## 推荐结论

建议选择 **方案 A：Python 正则表达式基础 v1**。

理由：

1. 范围足够窄，适合作为首个纵切片。
2. 可以同时验证语义理解、应用能力和独立解释。
3. 官方文档来源稳定，便于审查。
4. 后续可以用确定性测试验证正则表达式是否匹配预期文本。
5. 与当前代码库的技术语境一致，便于后续实现证据链。
