## 1. 可验证成果

> 学习者能够在不查阅资料的情况下，解释并编写基础 Python 正则表达式，用于匹配文本中的字面量、字符类、边界、量词和分组。

## 2. 验收维度

1. **语法语义**：解释字面量、字符类、锚点、量词和分组的作用。
2. **应用能力**：根据给定匹配任务编写正确的基础正则表达式。
3. **独立解释**：不依赖提示解释一个正则表达式的匹配行为和边界情况。

## 3. 证据配方

- 语法语义：至少 1 次 `semantic_analysis`，独立完成。
- 应用能力：至少 1 次 `deterministic_check`，独立完成。
- 独立解释：至少 1 次 `independent_review`，独立完成。

## 4. 边界

- 只覆盖 Python `re` 的基础语法。
- 不覆盖复杂回溯、性能优化或所有高级特性。
- 不把“能写出答案”直接等同于“稳定掌握”。
- 本版本发布后不可原地修改；后续调整必须创建新版本。
