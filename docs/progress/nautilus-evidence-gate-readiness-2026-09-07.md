## 2. PRD 11.4.2 阶段核对

### 2.1 候选主张引用链

**结论：通过。**

- 每条主张同时引用产出 ID、版本、事实事件 ID、标准 ID 和维度 ID。
- 证据：`test_evidence_claims.py`。

### 2.2 无引用的 AI 印象不能进入证据链

**结论：通过。**

- 只有分析成功且通过标准配方校验的 draft 才能写入主张。
- 无标准与失败运行不产生主张。
- 证据：`test_analysis_failures.py`。

### 2.3 Core 派生状态和原因标签

**结论：通过。**

- 状态包含 `awaiting_evidence`、`pending_review`、`insufficient_evidence`、`partially_supported`、`supported`、`contradicted`。
- 保存参与主张、排除主张、排除原因、标准版本和计算版本。
- 证据：`test_state_derivation.py`。

### 2.4 质疑后立即退出当前计算并保留历史

**结论：通过。**

- 质疑、撤回、替代会移出当前计算。
- 派生状态历史和复核动作保留。
- 证据：`test_state_derivation.py`、`test_review_workflow.py`。

### 2.5 批量与单条复核

**结论：通过。**

- 支持批量采纳和批量质疑。
- 每条主张仍有独立复核动作与审计。
- 批量采纳前仍逐条校验标准配方。
- 证据：`test_review_workflow.py`。

### 2.6 AI 故障与恢复

**结论：通过。**

- 覆盖不可用、超时、取消、输出不合格、权限拒绝和内部错误。
- 产出保存不受分析失败影响。
- 重试不重复产生事实或主张。
- 证据：`test_analysis_failures.py`。

### 2.7 重试幂等

**结论：通过。**

- 同一分析请求成功后重复提交返回原结果。
- 失败后重试产生新 attempt，但不重复主张。
- 证据：`test_analysis_failures.py`。

### 2.8 状态与复核回放

**结论：通过。**

- 证据主张、复核动作、批量复核、替代、状态和跟进均纳入事件账本。
- 证据回放校验哈希链并重建投影。
- 证据：`test_evidence_replay.py`。

### 2.9 事件版本升级

**结论：未通过。**

- 当前仅支持事件版本 1。
- 显式升级器或拒绝策略尚未实现。
- 归 Task 7/8。

### 2.10 删除、撤回与彻底删除

**结论：通过。**

- 普通删除可恢复。
- 撤回只改变证据适用性。
- 彻底删除清空内容并使依赖主张失效。
- 事实更正和主张替代已实现。
- 当前没有产品级缓存、搜索索引或备份对象需要清理。
- 证据：`test_artifact_lifecycle.py`、`test_privacy_deletion.py`。

### 2.11 全局 Agent 最小上下文

**结论：阶段通过。**

- 权限请求不包含原始产出内容。
- 默认最小摘要、状态和证据引用输出仍待 Task 8 的全量验收复核。
