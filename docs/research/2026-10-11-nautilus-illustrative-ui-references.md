# 插画型首页如何组织场景、卡片与导航

调研：2026-10-11。作者喜欢现有山海插画气质，但认为整页仍不协调，要求查看真实市场界面的处理方式。本文是观察与建议，不是已批准的重设计方案。

## 材料与结论范围

核对 Headspace、Balance、Finch、潮汐、Calm 的官网、官方商店展示和帮助文档；另查看 Meditopia 的近期商店图，未把它当成当前山海纸艺风格的直接同类。没有登录或安装体验，不推断设计团队意图或实际用户效果。商店图片可能是营销合成图；以下只分析其中可辨认的应用界面，不把手机外的宣传背景、口号或数字当成UI和效果证据。官网截图未注明版本时，只称公开示例。

[五个案例对照页](2026-10-11-illustrative-ui-comparison.html) · [对照图](2026-10-11-illustrative-ui-comparison.png)。图片保持原比例，各来源与抓取日期见[来源清单](assets/2026-10-11-illustrative-ui/sources.json)。公开参考图仅用于本次比较，不作为Nautilus产品素材。

本次观察到的共同做法：为图像、信息和操作划出稳定范围。不同主色可以共存，功能内容的承载方式、视觉层级和导航保持一致。没有证据说必须让整页所有图像使用同一颜色，或调底栏颜色就能解决整体构图。

## 五个可借鉴案例

### Headspace：插画主要在卡片一侧，文字区保持一致

官方商店的 Sleep 示例中，页面、卡片与导航沿用深蓝/紫色体系；卡片左侧是标题和说明，插画集中于右侧或角落。多个不同插画没有覆盖整张文字区域。[官方商店](https://apps.apple.com/us/app/headspace-sleep-meditation/id493145008)

借鉴判断：很适合研究老师与续学卡片的组织方式。可以保留自己的山海笔触、宋体气质和粉彩，不照搬其卡通人物或深色主题；先给文字、操作和插画明确区域，避免每个模块都成为一幅完整海报。它的配色与我们的原稿不同，参考的是组织方式。

### Balance：一个主要推荐，其余内容降低图像重量

官方 Today 展示有一张主要推荐卡：标题、居中插画、独立按钮按顺序排列；下面的 Daily Meditation 更紧凑，整体灰白底与导航一致。官方课程封面也以共同白底、有限的青绿强调和相近的插画尺度组织。[官方商店](https://apps.apple.com/us/app/balance-meditation-sleep/id1361356590)、[官网示例](https://themindcompany.com/apps/balance)

借鉴判断：建立主次，不让所有模块承担同等装饰重量。不能据此擅自降低老师或改变用户已认可的入口关系；需要单独审阅哪一部分作为主要视觉入口。Balance当前公开插画偏线描，并非与山海纸艺完全同款。

### Finch：有丰富场景，也有稳定的任务承载面

官方商店的场景/目标示例将角色与环境集中在上方，任务放在下方重复的浅色圆角条目里；任务文字、完成控件没有直接压在复杂的场景细节上。[官网及商店入口](https://finchcare.com/)、[官方商店](https://apps.apple.com/us/app/finch-virtual-self-care-pet/id1528595748)

借鉴判断：最值得拿来研究“装饰可以变化，任务仍然好读”的关系。对Nautilus可转化为：卡片背景允许用户更换，但标题、正文和按钮有一致的承载面与位置关系。本次没有验证Finch是否支持与Nautilus相同的任意卡片内容/排序能力，不能把它当作功能实现证据。

### 潮汐：整页自然场景配低密度操作

官网公开首页以一张海岸照片贯穿全屏，问候、四个主要操作和底部导航覆盖其上；页面没有再叠加三张各自完整的风景卡片。另一个睡眠截图只保留时间和少数操作。[官网公开截图](https://tide.fm/)

借鉴判断：可参考自然氛围与单一场景的完整性，但其首页信息密度明显低于我们的今日安排、老师和续学组合。更适合作为未来专注/沉浸页面的参考，不建议直接套到当前内容较多的首页；这只是建议，没有新增页面实施授权。

### Calm：内容封面多样，操作区域保持稳定

官方商店 Sleep 展示在统一深蓝界面上摆放不同风格的内容封面，分类、标题与导航属于稳定界面层，封面不负责整个页面的配色。官方另将可更换的首页场景作为单独的 Scene 功能。[官方商店](https://apps.apple.com/us/app/calm/id571800810)、[Scene说明](https://support.calm.com/hc/en-us/articles/115002474307-Calm-Scenes-Guide-Change-Background-Volume-Playback-Timer)

借鉴判断：让图片作为“内容封面”，与操作区域分工。即使允许用户换图，仍能保持文字和控件的稳定外观。本次对照用的是Sleep内容页，不把它冒充首页当前实机状态；Scene说明也不意味着我们的首页适合照搬全屏风景。

## 对当前Nautilus原稿的判断

颜色不协调是可见因素，但当前组合还同时拥有页头大场景、三张独立插画构图、多个太阳/海岸/室内景物和各自的完整卡片外观。图像占比及明暗层级相近，使各区都容易成为视觉中心。前几轮仅改背景和导航配色，未改变这层结构，因此不应继续把问题全部归到某个颜色上。

建议下一轮优先比较两种方向，均未批准：

1. **图文分区卡片**：借鉴Headspace，保留山海插画，但收进卡片一侧或固定封面区，正文和按钮有共同的干净表面；页面外壳保持稳定。适合承载当前较多内容，建议优先探索。
2. **一个场景＋功能卡片**：借鉴Finch的场景/任务分离，将主要意境集中使用，功能模块采用同一家族的容器。可继续保留换背景能力，但需要定义文字承载方式，不能把用户自定义取消为只能纯色。

要保留的约束：卡片内容、顺序、背景可自定义；不同卡片换序后不依赖拼景或最后一张卡片的颜色。现有默认顺序和业务语义不因本报告改变。插画原始比例必须保持，首页探索继续使用412:915画布；图片风格与页面结构可以分别找参考，再统一设计。
